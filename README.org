#+TITLE: org-learn.el — an Org-based learning helper for Emacs

org-learn.el is an Org-based learning helper: learning material lives in
Org files and the package helps you capture, review and grow it.  It is
built on Org mode and depends on org-roadmap for planning and progress
— a real but graceful dependency (spec 006).  The package loads and the
whole capture -> review -> grow loop works without org-roadmap
installed; only the roadmap commands need it, and they show a one-line
install hint when it is missing.  org-roadmap is a sibling package under
the khaalidrafi profile, still under development — nothing here blocks
on it.

* Installation

Both packages live on GitHub and install with straight.el (package-vc
works too: =M-x package-vc-install RET https://github.com/khaalidrafi/org-roadmap RET=).
org-roadmap is a REAL dependency (spec 006): install it first, then
org-learn.

#+begin_src elisp
;; org-roadmap — the planning/progress engine + roadmap.sh importer
(use-package org-roadmap
  :straight (org-roadmap :type git :host github
                         :repo "khaalidrafi/org-roadmap")
  :bind (("C-c r g" . org-roadmap-generate)          ; ASCII roadmap of the tree
         ("C-c r i" . org-roadmap-import-roadmap-sh) ; import by URL / JSON
         ("C-c r m" . org-roadmap-import-menu)       ; menu: every roadmap.sh roadmap
         ("C-c r a" . org-roadmap-agenda)))

;; org-learn — capture -> review -> drill loop on top
(use-package org-learn
  :straight (org-learn :type git :host github
                       :repo "khaalidrafi/org-learn.el")
  :hook (org-mode . org-learn-mode)
  :custom
  (org-learn-file "~/org/learning.org"))  ; where review items live
#+end_src

In an Org buffer with org-learn-mode on, the whole loop sits under
=C-c l= (=C-c l ?= lists every key).

* Quickstart

Fastest start — one click from zero to studying: run =M-x
org-learn-roadmap-menu= (=C-c l m=), pick any official roadmap.sh
roadmap (every role-based and skill-based roadmap is offered), accept
the study file, and the roadmap imports as an Org TODO tree, opens,
and gets one =:drill:= review item per topic — ready for =C-c l r=
(review) and =C-c l d= (drill).

Or the wizard: run =M-x org-learn-quickstart= (or press =C-c l q= in
an Org buffer with org-learn-mode on): one command walks you from zero
to the full loop in four skippable steps — learning file, first
capture, first review, and a tour of the =C-c l= keymap.  The wizard
never clobbers an existing learning file.

The loop in three commands:

1. =M-x org-learn-roadmap-menu= (=C-c l m=) — one click: pick a
   roadmap.sh roadmap, import it, board the review items
2. =C-c l c= — capture a learning note (=M-x org-learn-capture=)
3. =C-c l r= — review what is due (=M-x org-learn-review=)

Next steps (optional): plan one review item per topic of a roadmap TODO
tree with =C-c l p= (=M-x org-learn-plan-from-roadmap=) and watch
progress with =C-c P= (=M-x org-learn-progress-report=).  These need
the org-roadmap package installed (see the dependency note at the top
of this file); =M-x org-learn-quickstart= itself never requires it —
without it installed, those keys report a friendly install hint.

complete end to end — delivered modules (one spec each, specs/):
