#+TITLE: org-learn.el — an Org-based learning helper for Emacs

org-learn.el is an Org-based learning helper: learning material lives in
Org files and the package helps you capture, review and grow it.  It is
built on Org mode and depends on org-roadmap for planning and progress
— a real but graceful dependency (spec 006).  The package loads and the
whole capture -> review -> grow loop works without org-roadmap
installed; only the roadmap commands need it, and they show a one-line
install hint when it is missing.  org-roadmap is a sibling package under
the khaalidrafi profile, still under development — nothing here blocks
on it.

* Quickstart

Run =M-x org-learn-quickstart= (or press =C-c l q= in an Org buffer with
org-learn-mode on): one command walks you from zero to the full loop in
four skippable steps — learning file, first capture, first review, and
a tour of the =C-c l= keymap.  The wizard never clobbers an existing
learning file.

The loop in three commands:

1. =M-x org-learn-quickstart= — set up your learning file and see what
   every key does (=C-c l q=)
2. =C-c l c= — capture a learning note (=M-x org-learn-capture=)
3. =C-c l r= — review what is due (=M-x org-learn-review=)

Next steps (optional): plan one review item per topic of a roadmap TODO
tree with =C-c l p= (=M-x org-learn-plan-from-roadmap=) and watch
progress with =C-c P= (=M-x org-learn-progress-report=).  These need
the org-roadmap package installed (see the dependency note at the top
of this file); =M-x org-learn-quickstart= itself never requires it —
without it installed, those keys report a friendly install hint.

* Status

Built by a teamified agent chain on the agent-team kit
(https://github.com/khaalidrafi/agent-team-ci).  The learning loop is
complete end to end — delivered modules (one spec each, specs/):

- Capture — =org-learn-capture= and =org-learn-capture-from-region= (spec 001)
- Review — SM-2 scheduler, review sessions, agenda view (spec 002)
- Drill — cloze, two-sided, cram and leech sessions (spec 003)
- AI — tutor chat, flashcard and quiz generation, TRACE/FOCUS/CLEAR
  tutor modes, pluggable backend with a keyless default (specs 004, 007)
- Dashboard — study clock, retention stats, topic dashboard, roadmap
  rollup line (specs 005, 011)
- Roadmap — plan-from-roadmap, progress report and rollup over the
  real org-roadmap API (specs 006, 011)
- Fast start — =org-learn-mode= with one =C-c l= keymap, plus the
  quickstart wizard (specs 008, 010)
