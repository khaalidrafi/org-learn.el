#+TITLE: org-learn.el — an Org-based learning helper for Emacs

org-learn.el is an Org-based learning helper: learning material lives in
Org files and the package helps you capture, review and grow it.  It is
built on Org mode and depends on org-roadmap — a package under the
khaalidrafi profile that is not completed or published yet.  The
dependency is declared in the package header; the code does not require
it yet, and nothing here blocks on it.

* Status
