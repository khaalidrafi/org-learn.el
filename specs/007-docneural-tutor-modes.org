* Modes (each: interactive, works on the current subtree, renders in
* the *org-learn-ai-chat* buffer with the same turn rendering)
- =org-learn-ai-trace= — TRACE: the model walks the subtree material
  step by step (numbered steps, one idea per step, tiny example per
  step).  System prompt variant; the chat history stays multi-turn
  (follow-ups allowed).
- =org-learn-ai-focus= — FOCUS: the model asks ONE probing question on
  the material; read-string answer; model grades + explains + maps to
  quality 5|3|1 and offers org-learn-review--process-entry scheduling
  (same contract as spec 004 quiz — reuse its internals).
- =org-learn-ai-clear= — CLEAR: the model produces a compact summary:
  3 takeaway bullets + 3 cloze card suggestions in [answer||hint]
  form; offers org-learn-ai-generate-flashcards on the subtree.
