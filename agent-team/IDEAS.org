- org-drill (WORG, now MELPA-only): Org headings as flashcards, tag
  =:drill:=, card types via the =DRILL_CARD_TYPE= property (simple,
  cloze =[answer||hint]=, twosided, multisided, hide1/show1 cloze
  variants), recall rated 0-5 (SuperMemo labels), SM2/SM5/Simple8
  scheduling, cram sessions, leeches =:leech:= at repeated failures,

  capture templates, agenda views (custom commands), SCHEDULED /

* AI enhancements (Owner: MUST) — differentiators over org-drill
- Multi-turn AI tutor with the current subtree as context (keyless
  default lane: Pollinations text API, OpenAI-compatible; overridable
  endpoint/model/key — same keyless pattern the docneural tutor runs).
- One-command flashcard generation from any subtree (model returns
  Q/A pairs, we insert =:drill:= cards with =:CREATED_BY: ai=).
- AI quiz mode: model asks, user answers, model grades + explains.
- Everything degrades gracefully offline (user-error with a clear
  message); tests mock the network layer.
